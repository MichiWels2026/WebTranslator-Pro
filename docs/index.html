Datenschutzerklärung (Privacy Policy) – Forge WebTRANSLATOR OmniLingo PRO

Stand: Version 3.2.0

1. Verantwortlicher

MichisForgeTools – die in der Chrome-Erweiterung „Forge WebTRANSLATOR OmniLingo PRO" eingebettete KI-Sprach- und Übersetzungslösung.

2. Datenerhebung

Die Erweiterung erhebt keinerlei personenbezogene Daten über Sie oder Ihre Nutzung. Es werden keine Namen, E-Mail-Adressen, Standorte oder Inhalte an Dritte zur Speicherung oder Auswertung übermittelt.

3. Übersetzungsdaten

Turbo-Engine: Zur Übersetzung von Webseiten und Texten wird die öffentliche Google-Übersetzung API (translate.googleapis.com) verwendet. Dabei werden die zu übersetzenden Textinhalte technisch über die API übermittelt, um eine Übersetzung zu erhalten. Eine Zuordnung zu einer Person findet nicht statt.

Lokale KI-Engine (Ollama): Bei aktivierter lokaler KI-Engine bleiben alle Daten vollständig in Ihrem eigenen Browser / auf Ihrer eigenen Ollama-Instanz. Es findet keine Datenweitergabe an externe Dienste statt.

4. Lokale Speicherung

Alle Einstellungen (Sprache, Maschine, Tonfall, Glossar, Regeln) werden ausschließlich in der lokalen chrome.storage des Browsers Ihres Geräts gespeichert.

5. Hover-Vorschau & Inhalte

Die zur Anzeige des Originaltextes dienenden Hover-Vorschauen werden ausschließlich lokal im Browser verarbeitet und nicht übertragen.

6. Keine Cookies / Tracking / Telemetrie

Die Erweiterung verwendet keine Cookies, kein Tracking und keine Telemetrie.

7. Kontaktdaten

Bei Fragen zur Datenschutzerklärung: über die offiziellen Kanäle von MichisForgeTools.

8. Änderungen

Diese Erklärung kann bei Funktionsänderungen aktualisiert werden. Die aktuelle Version ist jederzeit in der Chrome-Erweiterung und in diesem Repository einsehbar.
